### Featured Projects

#### 🍔 [Café Nuwara — 3D Interactive Restaurant Web Experience](https://github.com/C-KAVISHKA/cafe-nuwara)
*An interactive 3D WebGL web platform built with Three.js, GSAP, and Tailwind CSS.*
* **Key Highlights:** Custom WebGL camera entrance sequences, scroll-triggered layer-by-layer burger anatomy breakdown, and 60 FPS Lenis smooth scrolling.
* **Tech Stack:** `Three.js` `WebGL` `GSAP ScrollTrigger` `Lenis` `JavaScript (ES6+)` `Tailwind CSS`
* 🔗 **[Explore Live Demo](https://cafe-nuwara.vercel.app)** &nbsp;•&nbsp; 💻 **[GitHub Repository](https://github.com/C-KAVISHKA/cafe-nuwara)**

#### 🛋️ [iFurnish Shop — 3D Spatial & WebXR E-Commerce Platform](https://github.com/C-KAVISHKA/iFurnish_Shop)
*A full-stack furniture shopping platform featuring browser-native 3D preview and augmented reality projection.*
* **Key Highlights:** Real-time 3D material/texture customization with Three.js, mobile WebXR AR room projection, persistent shopping cart, and Stripe payment workflows.
* **Tech Stack:** `React.js` `Three.js` `WebXR (AR)` `Node.js` `Express.js` `MongoDB` `Stripe`
* 🔗 **[Explore Live Demo](https://i-furnish-shop.vercel.app/)** &nbsp;•&nbsp; 💻 **[GitHub Repository](https://github.com/C-KAVISHKA/iFurnish_Shop)**

<br/>

#### 🏭 [ApparelFlow ERP — Garment Manufacturing Management Suite](https://github.com/C-KAVISHKA/apparelflow-erp)
*An enterprise resource planning solution tailored for apparel manufacturing workflows.*
* **Key Highlights:** Multi-tier production line order tracking, bill of materials (BOM), real-time inventory management, and role-based access control.
* **Tech Stack:** `TypeScript` `React.js` `Node.js` `Express.js` `MySQL` `RESTful APIs`
* 💻 **[GitHub Repository](https://github.com/C-KAVISHKA/apparelflow-erp)**

<br/>

#### 🏨 [Oceanview — Hotel & Resort Reservation System](https://github.com/C-KAVISHKA/oceanview-reservation-system)
